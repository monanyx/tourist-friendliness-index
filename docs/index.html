Method

Each venue's own website was crawled by a Python script that finds language versions, menu links and PDFs, flags scanned image menus, detects which languages the dishes are written in, and looks for an EU allergen legend and online booking. Every finding was then checked by hand before scoring. The crawler and the person caught different mistakes, which is the point of using both.

Only what a visitor can see online is measured. Printed menus, staff language skills and food quality are not part of the score.

Scope
